# 非天然酶反应的数据收集指南

你可以先从公开论文和 SI 录入，不需要提供未发表实验数据。先完成 5 篇的小批次，核对字段是否能表达真实化学，再扩大范围。

## 先填什么

1. 在 `反应条件` 表新建体系编号和发现事件编号，填写 DOI/链接、条件出处、反应名称、催化体系类型、蛋白骨架、实际金属/辅因子、原文条件摘录、核对状态。
2. 在 `实验结果` 表引用该体系编号，填写测量编号、实验编号、结果出处、化合物编号、实验阶段、检出状态、指标和原文结果。有数值时填写数值、比较符、单位。
3. SMILES 可以留空，结构状态填 `待补结构`。图表和化合物编号必须足够精确，以便后续补结构。

棕色表头表示固定必填项，浅色列可后补或按条件填写。酶催化的蛋白骨架、数值的单位/比较符等属于条件必填，详见字典。不确定的地方留空并写备注，不要为了填满表格猜信息。

## 三种编号怎样使用

| 编号 | 一条记录代表什么 | 何时新增 |
|---|---|---|
| 发现事件编号 | 文献中一项反应能力发现 | 新的发现事件；后续仍需跨论文核对是否重复发现 |
| 体系编号 | 反应模式、催化环境与操作条件 | 改金属、配体、光照、溶剂、反应条件或反应模式 |
| 实验编号 | 该条件下某底物、变体的一次实验或原文汇总实验 | 换底物、变体、独立重复；一个反应报告多个产物时保留同一实验编号 |
| 测量编号 | 对该实验某个产物的一个指标 | yield、ee、TTN各一条；不同产物的指标也各一条 |

编号示范 `MU2025_ENE_C01`、`MU2025_ENE_A01`、`MU2025_ENE_A01_YIELD`。它们只需稳定且唯一，不必提前设计复杂的分类体系。

**同一实验有两个产物时：** 可以在不同测量行填写不同产物 SMILES。`底物至产物编号` 对同一实验填写相同的完整列表，如 `1a + 2a → 3a, 4a`，在备注标明该行指标对应 3a 或 4a。不要把两种产物的 ee 合并。

## 每篇优先提取哪些内容

第一批优先录代表性底物，起始骨架/野生型的初始活性、最佳变体、关键中间变体（若能解释能力变化）以及无酶、无金属、暗条件等关键对照。先覆盖这些证据，再补大量底物拓展。

最有研究价值的差异经常不在最高产率，而在：哪个骨架一开始有微弱活性；换金属或活化条件后是否出现了新产物；哪些实验明确未检出。若论文只报告优化后结果，应如实记录，不能从最佳产率反推初始可行性。

## 数值和缺失值

| 原文 | 数值 | 比较符 | 单位 | 原文结果 |
|---|---:|---|---|---|
| 85% yield | 85 | = | % | 85% yield |
| <1% yield | 1 | < | % | <1% yield |
| >99% ee | 99 | > | % | >99% ee |
| 95:5 dr | 留空 | 留空 | ratio | 95:5 |
| n.d. | 留空 | 留空 | 留空 | n.d. |
| 未报告 | 留空 | 留空 | 留空 | 未报告 |

百分数单位列约定输入 0–100 标度，85 表示 85%，不要直接输入 Excel 的 `85%`（其底层值是 0.85）。如果已输入为 Excel 百分比，请改成普通数字 85。相对活性可能超过100%；ee若原文使用有定义的正负号可保留，注明定义。

若只报告 `n.d.`，指标可选 `product_detected`，只填原文结果和未检出状态，不必推导检测限为零。若明确记录检出布尔值，也可用数值 0/1、单位 boolean、比较符 =。

## 结构与条件

- 反应 SMILES 支持 `reactants>>products` 和 `reactants>agents>products`，多组分用 `.` 分开。无需原子映射，保留立体信息。
- 原文的反应参与物与催化剂/溶剂应按化学角色区分。结构检索暂不使用 agents 段；条件原文另行保留，避免把催化体系信息丢掉。
- 未检出实验可记录文献明确测试的目标转化，产物角色选 `测试目标`；不能凭空补一个“应该生成”的产物。
- 天然 Fe、实际加入的 Cu 盐、金属置换方式分别录入。仅凭加铜盐不推断活性物种价态或特定催化循环。
- pH、温度、溶剂、时间、底物浓度、酶/金属用量、光照/供电子条件都保留单位。第一遍可整体放入原文条件摘录，避免因拆字段而拖慢录入。
- 机理标签可以空着；填写时同时写明作者提议、实验支持还是项目假设，并提供出处。

## 第一批论文队列

以下只是优先核对的入口，尚未把论文的结构、数值或最早公开日期人工录入完成。你熟悉的课题组新文章可以优先替换；每条都回到原文及 SI。

| 入口 | 优先核查什么 |
|---|---|
| [Mu et al., Cu置换非血红素酶 ene 反应，2025](https://www.nature.com/articles/s41929-025-01350-5) | 实际金属、初始骨架活性、Lewis酸活化证据、条件与对照 |
| [Shen et al., Cu置换酶 C(sp³)–N 偶联，2025](https://pubmed.ncbi.nlm.nih.gov/40811552/) | 金属置换、外部伙伴、起始与进化后结果 |
| [Wang et al., Ni置换酶 C(sp²)–S 偶联，2026](https://www.nature.com/articles/s44160-026-01003-w) | 配位环境、光驱动、金属/光对照、是否已有更早预印本 |
| [Kan et al., cytochrome c C–Si 成键，2016](https://pubmed.ncbi.nlm.nih.gov/27885032/) | 已有数据能否复用；初始与最佳变体分开；非酶先例链 |
| [Miller et al., aziridine→azetidine Stevens 重排](https://authors.library.caltech.edu/records/4n9cr-qyw64) | 2021预印本与2022期刊日期；蛋白改变竞争路径的证据 |

每篇若同时提到关键小分子催化先例，可以在同一模板补录，催化体系类型选 `非酶催化`。这里要保存真实先例，而不是把“未找到酶促报道”当失败标签。

## 如何交回

直接填写 Excel 两张主表并保存。不要改表名和表头，不要合并单元格；超过200行可复制末行格式。参考说明和示例表不进入导入。

推荐第一批保留 `待核对` 状态。后续一起核对结构、合并重复发现事件、统一反应模式与条件词汇，然后才能加入正式索引和评估集。
